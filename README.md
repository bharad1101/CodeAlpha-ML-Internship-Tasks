## Overview
This repository contains Machine Learning internship tasks completed under CodeAlpha.

The projects focus on predictive analytics, deep learning, computer vision, and speech emotion recognition.

## Projects Included

### Credit Scoring Model
Predicts customer creditworthiness using Machine Learning algorithms.

### Emotion Recognition
Speech emotion recognition system using audio processing and ML.

### Handwritten Digit Recognition
CNN-based handwritten digit classifier using image datasets.

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- Scikit-learn
- NumPy
- Pandas
